# Especialista Agritech do ARGOS

## Sobre o agente

O Especialista Agritech do ARGOS é um agente de inteligência artificial criado para apoiar a equipe em pesquisas técnicas, sanitárias, mercadológicas e de experiência do usuário relacionadas à pecuária bovina.

O agente transforma informações verificadas em recomendações práticas para o desenvolvimento do ARGOS.

## Acesso

[Conversar com o Especialista Agritech do ARGOS](COLE_AQUI_O_LINK_DO_AGENTE)

## Principais funções

- Pesquisar processos sanitários da pecuária bovina.
- Apoiar a definição de regras de negócio.
- Analisar soluções e concorrentes do mercado Agritech.
- Consultar informações públicas sobre medicamentos veterinários.
- Auxiliar na organização do registro e da rastreabilidade de medicamentos.
- Sugerir melhorias de UX/UI para utilização no ambiente rural.
- Identificar oportunidades de diferenciação para o ARGOS.
- Traduzir informações técnicas e normas em ações compreensíveis para a equipe.
- Apresentar links para as fontes consultadas.

## Limites importantes

O agente:

- Não substitui um médico-veterinário.
- Não realiza diagnósticos ou prescrições.
- Não deve inventar períodos de carência.
- Não deve apresentar sugestões como requisitos já aprovados.
- Não deve inventar funcionalidades ou preços de concorrentes.
- Deve informar quando não encontrar fontes suficientemente confiáveis.
- Considera somente os requisitos do primeiro ano nesta etapa do projeto.

Informações sanitárias devem ser confirmadas em fontes oficiais e, quando necessário, por um médico-veterinário responsável.

## Exemplos de perguntas

- Quais informações devem ser registradas durante a aplicação de um medicamento em um bovino?
- Como os concorrentes apresentam o cadastro dos animais?
- Quais dados seriam necessários para acompanhar um período de carência?
- Como transformar uma regra sanitária verificada em uma funcionalidade do ARGOS?
- Como simplificar determinado fluxo para utilização no campo?
- Quais informações ainda precisam ser validadas com um veterinário?
